# Estándares del proyecto

- [`ciudad.md`](./ciudad.md): estándar obligatorio de calidad visual, técnica y documental para toda ciudad publicada.
- [`auditoria-ciudades.md`](./auditoria-ciudades.md): estado real de las seis ciudades frente al estándar y siguiente acción.

El estándar es normativo: una ciudad no se marca `available` solo porque tenga un GLB. Debe cumplir los gates de modelo, evidencia, rendimiento y QA descritos en `ciudad.md`.

La referencia visual es **Chavín v0.4**; la referencia técnica y de cierre de contenido es **Caral v2**. No se copian arquitectura, paleta ni materiales de una ciudad a otra.
