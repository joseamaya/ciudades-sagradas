# Chavín de Huántar — remaster

Estado: **blockout v0.5 aceptado como escala; texturizado UV v0.1 de la mampostería ashlar en revisión**. Fuentes UNESCO/Mincul, Plan de Manejo 2020 e ICOMOS 1999 verificados; ICOMOS 1985 y las secciones finas quedan como pendientes no bloqueantes. No hay assets web publicados.

Chavín se abre después del cierre de contenido de Caral v2. El blockout v0.5 está aceptado como base de escala y `chavin_textured_v0.1.blend` añade UVs de proyección cúbica y texturas 2K repetidas. El bake 2K se probó y se descartó por pérdida de detalle. El modelado final sigue condicionado a los permisos de publicación; el terreno se queda procedural por ahora.
