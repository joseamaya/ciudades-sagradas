# Informes Playwright

Informes generados por `tests/qa/` el 30 de octubre de 2026.

- `chromium-desktop/`: Chromium desktop 1600×900 con SwiftShader.
- `chromium-mobile/`: Pixel 7 emulado, con LOD1 automático y LOD0 forzado en las pruebas de evidencia.
- `firefox-desktop/`: Firefox headless 1600×900 con GPU enmascarada.

Los FPS y tiempos de carga son de renderizado headless/emulado. **No son métricas de hardware real y no deben mezclarse con el informe de Intel RPL-S** en `docs/qa/resultados/2026-10-30-caral-desktop-intel-lod0.json`.

La lectura y las limitaciones están en [`../../revision-playwright.md`](../../revision-playwright.md).
