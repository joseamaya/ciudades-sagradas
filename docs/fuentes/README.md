## Criterios

- Fuentes oficiales primero: UNESCO, ICOMOS, Ministerio de Cultura, museos y proyectos de investigación.
- Academia open access cuando aporta detalle.
- Wikipedia no se usa como fuente final; solo como orientación.
- Cada dato dudoso se marca como inferido o interpretativo.
- Las imágenes oficiales se citan; no se copian sin permiso.
