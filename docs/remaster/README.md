# Remasterizaciones

El estándar de calidad es [`../estandares/ciudad.md`](../estandares/ciudad.md). Toda ciudad publicada debe cumplirlo; la auditoría está en [`../estandares/auditoria-ciudades.md`](../estandares/auditoria-ciudades.md). La caché vigente es la global `ciudades-sagradas-v36`; las menciones a `v7`, `v22`, `v27` o `v34` en documentos de release son históricas.

- [Caral](./caral/README.md): remaster v2 desplegado y contenido cerrado como ciudad representativa; LOD0/LOD1 con Draco y fallback v1. Es la plantilla técnica del proyecto. Incidencia Android P2 documentada.
- Chavín de Huántar: preview web v0.3 con pase de valle v0.7; LOD0 de 249.830 tris y LOD1 de 42.951 tris medidos por accessors; Mosna ~30 m abajo, Wacheqsa al norte, Lanzón derivado del escaneo CyArk (CC BY-NC-SA 4.0) y Portada con fustes acanalados. Dintel, escalera completa y QA móvil/1080p pendientes.
- [Aypate](./aypate/README.md): preview web v0.4 con high-poly navegable; LOD0 de 209.560 tris y LOD1 de 30.663 tris. Núcleo inca, Qhapaq Ñan y bosque de neblina, con layout macro y escala contrastados con el plano de 2013. Cierre de cotas de conjunto en `aypate/cotas.md`; QA de hardware y cotas finas pendientes.
- [Narihualá](./narihuala/README.md): preview web v0.2 interpretativo; LOD0 de 162.432 tris y LOD1 de 29.682 tris. Montículo este y capilla desde SIGRID 2018; montículo oeste, plaza y accesos inferidos; rampas documentadas no modeladas. Capilla en capa `later`; cotas finas pendientes.
- Chan Chan y Wari: en investigación; quedan en segundo plano frente a Aypate y Narihualá.
