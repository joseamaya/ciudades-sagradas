# Chavín — decisiones de contenido y licencia

Fecha: 4 de noviembre de 2026.
Alcance: preview web v0.3 y pase de escena v0.7.
Referencias: [`cobertura.md`](./cobertura.md), [`portada-v0.1.md`](./portada-v0.1.md), [`../../fuentes/chavin.md`](../../fuentes/chavin.md), [`LICENSE-ASSETS.md`](../../../LICENSE-ASSETS.md) y [`docs/kiosco.md`](../../kiosco.md).

## D-CH-001 — Dintel de la Portada

| Campo | Valor |
|---|---|
| Decisión | **No reconstruir el dintel** en el preview. |
| Evidencia | Documentado que el dintel de tres piezas no forma parte de la reconstrucción actual; no hay cota fiable para modelarlo. |
| Estado | Cerrada para v0.3/v0.7. |
| Impacto | La Portada se lee con columnas, jambas y friso; el vano queda sin dintel. Se indica en la ficha y en este documento. |
| Revisión | Solo si aparece un levantamiento publicado con medidas verificables. |

## D-CH-002 — Escalera de acceso

| Campo | Valor |
|---|---|
| Decisión | **Un escalón inferido**, sin desarrollar una escalera completa. |
| Evidencia | No hay cota fiable del desarrollo; el escalón se marca como inferido. |
| Estado | Cerrada para v0.3/v0.7. |
| Impacto | La escalera no se presenta como documentada ni se inventan peldaños. |
| Revisión | Si aparece una sección o levantamiento con cotas. |

## D-CH-003 — Licencia del Lanzón

| Campo | Valor |
|---|---|
| Decisión | **Mantener el escaneo solo para el preview no comercial**, con atribución y compartir igual. No se autoriza un kiosco de pago ni un uso comercial con el GLB actual. |
| Licencia | CC BY-NC-SA 4.0 para la geometría derivada del Lanzón; el resto del proyecto sigue CC BY 4.0 y el código MIT. |
| Opciones evaluadas | 1) Pedir licencia comercial a CyArk/Google Arts & Culture. 2) Sustituir el Lanzón por una malla propia. 3) Mantener el escaneo y restringir los usos. |
| Decisión tomada | Opción 3 para el preview actual. La opción 1 o 2 es requisito antes de cualquier kiosco con entrada de pago o patrocinio. |
| Impacto | El kiosco público gratuito puede mantener Chavín con atribución; un despliegue comercial debe sustituir la malla o negociar una licencia. |
| Revisión | Antes de abrir un kiosco comercial o aceptar patrocinio; también si CyArk publica términos compatibles. |

La evaluación legal definitiva corresponde al titular del despliegue. Este documento fija el criterio técnico del repositorio, no sustituye una licencia.

## Uso en kiosco

- Chavín se puede mostrar en el preview público no comercial con la atribución del Lanzón.
- No se debe presentar el GLB actual como material comercial ni vender acceso a una experiencia que lo incluya.
- Para un kiosco de museo con entrada o patrocinio: sustituir el Lanzón por una malla propia o obtener licencia comercial.
- El resto de la ciudad (arquitectura, terreno, materiales propios) no tiene esa restricción.
