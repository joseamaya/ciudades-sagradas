## Alcance

El piloto documental se conserva como base de evidencia. El preview 3D se limita al **núcleo monumental**: Vegachayoc Moqo, Capillapata, Monqachayoc y Cheqo Huasi, no a las 2.000 ha del sitio.

- GLB LOD0/LOD1, `hero.jpg`, seis paradas, cuatro capas y cuatro presets de luz.
- LOD0: 158.216 tris / 1,8 MB; LOD1: 26.224 tris / 0,7 MB; 15/13 draw calls; texturas 176/80 MB de VRAM estimada.
- Templos en D, muros dobles, plazas, galerías, patios y terrazas.
- No se copian fotografías oficiales de Ministerio de Cultura, museos ni academia; no hay texturas de IA.
- No se presenta como ciudad inca ni como reconstrucción arqueológica final.

## Decisión

**Decisión actual (4 de noviembre de 2026):** se construye un preview 3D del núcleo monumental. El trazado urbano completo, las alturas, los techos, la policromía y la población se presentan como discutidos, inferidos o interpretativos, nunca como hechos cerrados. La QA de hardware sigue pendiente; no se publica como `released`.

Wari no figura en la Lista del Patrimonio Mundial; su ficha se apoya en Ministerio de Cultura, museos y academia. Ver [`plan-3d.md`](./plan-3d.md).
