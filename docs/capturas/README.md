# Capturas

Todas las capturas de esta carpeta corresponden a **Caral Remaster v2** (LOD0/LOD1, seis paradas) salvo que se indique lo contrario.

- `atlas.png`: catálogo de ciudades en escritorio.
- `movil-atlas.png`: catálogo en móvil.
- `caral-ficha.png`: Caral v2 con la ficha abierta.
- `caral-limpio.png`: Caral v2 sin interfaz (tecla H).
- `caral-atardecer.png` y `caral-noche.png`: presets de luz de v2.
- `kiosco.png`: modo museo a 1920 × 1080.
- `chavin-investigacion.png`: ficha en investigación.

Las reconstrucciones son artísticas, no fotografías históricas. Las capturas del piloto histórico con texturas de IA fueron retiradas del repositorio.
