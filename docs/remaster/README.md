# Remasterizaciones

El estándar de calidad es [`../estandares/ciudad.md`](../estandares/ciudad.md). Toda ciudad publicada debe cumplirlo; la auditoría está en [`../estandares/auditoria-ciudades.md`](../estandares/auditoria-ciudades.md).

- [Caral](./caral/README.md): remaster v2 desplegado y contenido cerrado como ciudad representativa; LOD0/LOD1 con Draco y fallback v1. Es la plantilla técnica del proyecto. Incidencia Android P2 documentada.
- Chavín de Huántar: preview web v0.2 con pase high-poly v0.4; LOD0 de 249.906 tris y LOD1 de 27.539 tris; friso integrado, Lanzón derivado del escaneo CyArk (CC BY-NC-SA 4.0) y Portada con fustes acanalados. Dintel, escalera completa y QA en hardware real pendientes.
- [Aypate](./aypate/README.md): preview web v0.4 con high-poly navegable; LOD0 de 209.560 tris y LOD1 de 30.663 tris. Núcleo inca, Qhapaq Ñan y bosque de neblina, con layout macro y escala contrastados con el plano de 2013. Cierre de cotas de conjunto en `aypate/cotas.md`; QA de hardware y cotas finas pendientes.
- [Narihualá](./narihuala/README.md): preview web v0.2 interpretativo; LOD0 de 175.724 tris y LOD1 de 26.894 tris. Montículo este y capilla desde SIGRID 2018; montículo oeste, plaza y rampas inferidos. Capilla en capa `later`; cotas finas pendientes.
- Chan Chan y Wari: en investigación; quedan en segundo plano frente a Aypate y Narihualá.
